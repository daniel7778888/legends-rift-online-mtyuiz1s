# Rift Map Study

Интерактивная оригинальная 3D MOBA-карта в мультяшном фэнтези-стиле: Светлая и Тёмная стороны, три дороги, река, каменный мост, лесные зоны, башни, базы, руины и атмосферное освещение. В `src/assets/player.glb` добавлена пользовательская модель персонажа.

## Управление

- Один палец / ЛКМ — поворот камеры.
- Два пальца / колесо мыши — приближение и отдаление.
- Кнопка **Вид сверху** — вернуть художественный обзор карты.

## Запуск — без сервера

После сборки откройте **`index.html`** в файловом менеджере или браузере: карта запускается напрямую, без Vite, localhost и Termux-сервера. Файлы `app.js` и `app.css` уже собраны и лежат рядом с ним. GLB встроен в `app.js`, поэтому браузер не блокирует модель при прямом запуске.

После изменения исходников пересоберите автономную версию:

```bash
cd /sdcard/Download/LegendsOfTheRiftMobile
bash build-direct.sh
```

Скрипт использует временную приватную папку Termux только для компиляции. Готовая карта всё равно запускается обычным нажатием на `index.html`.

## Структура

- `src/core` — Three.js приложение и управление камерой;
- `src/world` — генерация геометрии карты, окружения и загрузка GLB-персонажа;
- `src/ui` — UI и мини-карта;
- `src/styles.css` — адаптивная оболочка для телефона.
